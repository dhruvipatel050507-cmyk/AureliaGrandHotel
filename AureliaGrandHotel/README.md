# 🏨 Aurelia Grand Hotel Management System

A luxury Hotel Management System developed using Spring Boot, Thymeleaf, Hibernate, and MySQL.


# 🚀 Features

## 👤 User Features
- User Registration & Login
- Browse Luxury Rooms
- Room Booking System
- Online Payment Flow
- Booking History
- Refund Request System
- Restaurant & Food Menu
- Events Booking
- Services Management
- Contact System


## 🔐 Admin Features
- Admin Dashboard
- Manage Rooms
- Manage Users
- Manage Bookings
- Manage Refunds
- Manage Services
- Manage Events
- Manage Food Menu
- Manage Messages


# 🛠 Technologies Used

- Java
- Spring Boot
- Spring MVC
- Hibernate / JPA
- Thymeleaf
- MySQL
- Bootstrap
- HTML/CSS/JavaScript


# 💾 Database

MySQL Database Name:

aurelia_hotel



# ⚙️ Application Properties

properties
spring.application.name=AureliaGrandHotel

spring.datasource.url=jdbc:mysql://localhost:3306/aurelia_hotel
spring.datasource.username=root
spring.datasource.password=

spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=true

spring.thymeleaf.cache=false

server.port=8080



# ▶️ Run Project

## Step 1
Clone Repository

bash
git clone https://github.com/YOUR_USERNAME/AureliaGrandHotel.git


## Step 2
Open in Eclipse / IntelliJ

## Step 3
Create MySQL Database

sql
CREATE DATABASE aurelia_hotel;

## Step 4
Run Spring Boot Application

## Step 5
Open Browser

http://localhost:8080/
